
## Project Overview

This project explores global fuel price patterns, estimated taxation, and estimated subsidies across different regions, countries, fuel types, and income groups from 2020 to 2026.

It combines an interactive web dashboard with Tableau visualizations to help users explore patterns, compare categories, and understand the potential relationships between fuel prices, taxes, and subsidies.

## Project Objectives

* Explore fuel price trends over time.
* Compare estimated tax and subsidy shares across regions.
* Examine relationships between fuel prices, taxation, and subsidies.
* Compare fuel costs across countries and income groups.
* Present data insights through interactive visualizations.

## Key Visualizations

* Fuel Price Trend
* Regional Fuel Costs
* Country Price Rankings
* Regional Tax Comparison
* Price vs. Tax Relationship
* Subsidy vs. Fuel Price Relationship
* Quarterly Fuel Price Movements
* Tax Share by Income Group
* Taxation vs. Subsidies

## Interactive Website Features

* Filters for year, region, fuel type, and income group.
* Summary metrics that update with selected filters.
* Interactive charts and country comparisons.
* CSV export for the displayed dataset.
* Responsive layout for desktop and mobile screens.

## Tools and Technologies

* **Tableau Public** — data visualization and dashboard development.
* **HTML** — website structure.
* **CSS** — styling and responsive layout.
* **JavaScript** — filtering and interactive features.
* **Chart.js** — interactive charts.
* **GitHub** — version control and project hosting.
* **GitHub Pages** — website deployment.

## How to Run the Website

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Ensure you have an internet connection so the Chart.js library can load.

The website can also be published using GitHub Pages.

## Data Disclaimer

**Important:** The values used in this portfolio project are simulated demonstration data. They are not verified historical fuel prices, tax rates, or subsidy figures. The results are intended only to demonstrate data visualization and analytical techniques and should not be used for real-world policy, financial, or business decisions.
