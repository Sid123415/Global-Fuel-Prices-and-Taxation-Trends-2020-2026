# Global Fuel Prices and Taxation Trends — Interactive Website

A responsive interactive companion website for the Tableau portfolio project.

## Features
- Filters for year, region, fuel type, and income group
- KPI cards that update with the selected data
- Interactive charts for trends, country rankings, regional costs, taxes, and subsidies
- Filtered country comparison table
- CSV export of the selected data
- Responsive desktop and mobile design

## Data disclaimer
All values shown are **simulated demonstration data** generated for this portfolio prototype. They are not verified historical fuel prices, tax rates, or subsidy figures and must not be used for real-world policy or business decisions.

## Run locally
Open `index.html` in a browser with an internet connection (Chart.js is loaded from a CDN).

## Publish with GitHub Pages
1. Upload `index.html` and `README.md` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for the site URL to appear on the Pages settings screen.
